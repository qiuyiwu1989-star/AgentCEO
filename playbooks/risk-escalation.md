# Playbook: 风险升级

> 当出现法律、品牌、财务、客户、数据、人事、伦理、AI 越权等高风险事项时，按此流程处理。不自动推进，不隐瞒风险。

---

## 触发信号

- 涉及法律、合同、知识产权
- 涉及客户承诺、报价、交付周期
- 涉及品牌发布、公关危机
- 涉及财务支出、预算调整
- 涉及人事任免、绩效判断
- 涉及数据安全、隐私
- 涉及伦理争议
- AI 自动执行高风险任务
- 证据不足但影响重大

---

## 风险类型与等级

### 九类风险

| 类型 | 说明 |
|------|------|
| 战略风险 | 方向偏离、资源分散、窗口错判 |
| 执行风险 | 任务失控、质量不达标、延期 |
| 财务风险 | 超支、现金流、投资回报不足 |
| 法律风险 | 合同纠纷、知识产权、合规 |
| 品牌风险 | 声誉受损、负面舆情、形象偏差 |
| 数据安全风险 | 数据泄露、权限越界、隐私侵犯 |
| 伦理风险 | AI 决策偏见、公平性、透明度 |
| 人事风险 | 关键人离职、团队冲突、激励失效 |
| AI 越权风险 | Agent 超出授权范围执行 |

### 四个等级

| 等级 | 处理方式 |
|------|---------|
| 低 | 记录，继续推进 |
| 中 | 标注风险，增加审核节点 |
| 高 | 暂停推进，升级人类确认 |
| 红线 | 立即停止，必须人类介入 |

---

## 执行流程

### 第一步：识别风险

- 当前出现了什么风险？
- 属于哪种风险类型？
- 已经发生还是可能发生？

### 第二步：判断等级

- 影响范围多大？
- 是否可逆？
- 是否涉及法律/品牌/财务/人事/伦理/数据？
- 是否涉及 AI 越权？

### 第三步：评估当前状态

- 已经发生了什么？
- 已采取了什么措施？
- 还可能恶化到什么程度？

### 第四步：提出处理方案

- **继续推进**：低风险，可控制
- **增加审核**：中风险，加检查点
- **暂停**：高风险，等人类确认
- **降级**：缩小范围，降低风险
- **拒绝/停止**：红线风险，立即停止

### 第五步：升级

升级时必须说明：
- 升级原因
- 事项背景
- 当前状态
- 关键风险
- 备选方案
- 范德建议
- 需要人类确认的具体事项
- 确认截止时间
- 未确认前处理方式

### 第六步：沉淀风险规则

- 是否需要转化为风险规则？
- 是否需要更新权限边界？
- 是否需要加入红线清单？

```

风险事项：
风险类型：战略 / 执行 / 财务 / 法律 / 品牌 / 数据安全 / 伦理 / 人事 / AI越权
风险等级：低 / 中 / 高 / 红线
风险表现：
影响范围：
当前状态：已发生：/ 可能恶化：
处理选项：继续 / 增加审核 / 暂停 / 降级 / 拒绝 / 升级人类
范德建议：
需要确认：谁确认？/ 确认什么？/ 最晚何时？
未确认前处理：
沉淀建议：是否需要转化为风险规则？
```

---

## 升级规则

所有高风险事项都应升级。涉及 L3、L4 决策必须暂停自动执行。
