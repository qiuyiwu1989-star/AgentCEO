# Playbook: 项目延期诊断

> 当项目或任务未按计划完成、出现延期、拖延或无进展时，按此流程诊断。不只催进度，要找根因。

---

## 触发信号

- 任务超过截止时间
- 项目长期进行中
- 关键节点未完成
- 负责人无更新
- 交付物未出现
- 反复调整截止时间
- "这个项目怎么还没完成？"

---

## 延期原因分类

延期不一定是执行力问题，可能来自七种原因：

| 原因类型 | 典型表现 |
|---------|---------|
| 目标问题 | 目标不清、目标变化、目标冲突 |
| 责任问题 | 没有主责、责任模糊、负责人缺位 |
| 资源问题 | 人力不足、时间不足、关键人过载 |
| 依赖问题 | 等待上游、等待外部、等待确认 |
| 能力问题 | 缺少Skill、缺少知识、Agent不稳定 |
| 优先级问题 | 被其他项目挤占、注意力分散 |
| 外部风险 | 客户变化、市场变化、政策变化 |

---

## 执行流程

### 第一步：确认原目标和原计划

- 原目标是什么？
- 原截止时间是什么？
- 原交付物是什么？
- 原负责人是谁？

### 第二步：检查当前状态

- 目前完成了什么？
- 还差什么？
- 最近一次更新是什么时候？
- 完成比例是多少？

### 第三步：诊断延期原因

按七种原因逐一排查：
1. 目标是否清晰？
2. 责任是否明确？
3. 资源是否充足？
4. 是否有依赖阻塞？
5. 能力是否匹配？
6. 优先级是否正确？
7. 是否有外部风险？

### 第四步：判断影响范围

- 影响哪些下游项目？
- 影响哪些客户？
- 影响哪些团队？
- 影响后续哪些任务？

### 第五步：提出处理方案

根据原因选择：
- **继续推进**：原因明确，可解决
- **调整排期**：时间不够，重新安排
- **增加资源**：投入不足
- **降低范围**：缩小交付物
- **暂停**：等待条件成熟
- **取消**：不值得继续
- **升级**：需要人类介入

### 第六步：更新看板

- 更新任务状态
- 设置新截止时间
- 设置检查节点

---

## 输出模板

```
【项目延期诊断】

项目/任务名称：
原计划：目标：/ 截止时间：/ 交付物：/ 负责人：
当前状态：完成了什么？/ 还差什么？
延期原因：目标问题：/ 责任问题：/ 资源问题：/ 依赖问题：/ 能力问题：/ 优先级问题：/ 外部风险：
影响范围：
处理建议：继续 / 调整排期 / 增加资源 / 降低范围 / 暂停 / 取消 / 升级
新计划：截止时间：/ 责任人：/ 检查节点：
是否需要复盘：是 / 否
需要人类确认：
```

---

## 升级条件

延期影响客户承诺、外部交付、预算、品牌、关键战略项目或多个团队时，必须升级。
