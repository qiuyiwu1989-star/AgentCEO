# Contributing to AgentCEO

Thanks for helping build the Management Layer for AI Agents.

## Contribution Areas
- Kernel rules (`/kernel`)
- Prompt Pack (`/prompts`)
- Playbooks (`/playbooks`)
- Templates (`/templates`)
- Examples (`/examples`)
- Documentation (`/docs`)

## Principles
- Keep outputs executable, not just conceptual.
- Preserve decision boundaries and human sovereignty.
- Include risk escalation logic when relevant.
- Add learning/retrospective outputs for reusable organizational memory.

## Pull Request Checklist
- Explain what management capability is improved.
- Include before/after behavior when possible.
- Keep naming and structure aligned with README and ROADMAP.
