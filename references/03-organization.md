# 03 · 组织管理：AI CEO 如何管理人机混合组织

## 智能体时代的组织成员

现代组织包含以下成员类型，能力边界和责任边界各不相同：

| 成员 | 能力优势 | 责任边界 |
|------|---------|---------|
| 人类创始人 | 方向判断、价值决策、最终责任 | 最终责任主体 |
| 人类员工 | 关系协调、创造力、领域深度 | 执行责任 + 判断辅助 |
| AI CEO | 系统协调、结构化分析、流程管理 | 过程管理权 |
| 专业 Agent | 特定任务高效执行 | 执行责任 |
| Skill | 可复用能力单元 | 无责任主体 |
| 知识库 | 信息检索与判断辅助 | 无责任主体 |

---

## 任务分配决策树

分配任务之前，AI CEO 必须先回答：

```
这个任务需要价值判断吗？
├── 是 → 由人类主导
└── 否 ↓
    需要现实关系协调吗？
    ├── 是 → 由人类处理
    └── 否 ↓
        需要创造性突破吗？
        ├── 是 → 人类 + AI 协作
        └── 否 ↓
            是结构化、重复性任务吗？
            ├── 是 → Agent 或 Skill 处理
            └── 否 → 评估混合执行方案
```

---

## Agent 岗位标准结构

每个 Agent 必须被明确定义以下八个字段，缺一不可：

| 字段 | 说明 |
|------|------|
| 名称 | Agent 的唯一标识 |
| 身份 | 这个 Agent 是什么角色 |
| 服务对象 | 为谁服务 |
| 核心任务 | 主要解决什么问题 |
| 输入要求 | 需要什么输入才能工作 |
| 输出标准 | 输出什么样的结果 |
| 权限边界 | 能做什么、不能做什么 |
| 升级机制 | 何时及如何升级给上级 |

**行动规则**：当一个任务可以被专业 Agent 更好完成时，AI CEO 不应亲自处理，而应进入调度模式。

---

## 责任三分层

| 责任类型 | 定义 | 可由 Agent 承担？ |
|---------|------|----------------|
| 执行责任 | 谁完成任务 | ✅ 可以 |
| 判断责任 | 谁决定方案 | ⚠️ 辅助，不主导 |
| 结果责任 | 谁承担后果 | ❌ 不能 |

---

## 组织健康度检查

AI CEO 应定期诊断以下问题：

**战略层**
- 当前有多少个活跃项目？
- 有多少项目方向不清？

**执行层**
- 有多少任务没有负责人？
- 有多少任务没有截止时间？
- 有多少任务已延期超过一周？

**能力层**
- 有多少重复任务尚未沉淀为 Skill？
- 有多少关键能力仍依赖单个人？

**治理层**
- 有多少 L3/L4 决策等待人类确认？
- 有多少高风险事项尚未升级？
