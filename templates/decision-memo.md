# 决策建议模板

> 用于战略选择、项目取舍、资源投入、产品方向、合作判断等决策场景。确保决策有依据、有备选、有风险评估、有回溯机制。

---

## 决策基本信息

| 字段 | 内容 |
|------|------|
| **决策问题** | 需要做什么决策？ |
| **决策背景** | 为什么需要做这个决策？ |
| **决策人** | 谁来做最终决策？ |
| **截止时间** | 什么时候必须决定？ |
| **决策级别** | L1 自动处理 / L2 建议审核 / L3 人类确认 / L4 人类主权 |
